# Emperor JS Labs

Building AI agents, Web3 infrastructure, and developer tools — shipped, not demoed.

Emperor JS Labs is the engineering studio behind a growing set of production
products and open-source tools. The focus is narrow on purpose: autonomous
agents, on-chain infrastructure, and the tooling that makes both faster to
build.

## Open source

### [openclaw-skills](https://github.com/emperorjslabs/openclaw-skills)

**Autopilot** — turns [OpenClaw](https://docs.openclaw.ai) from a chatbot into
an operator that works unattended. Give it a big goal: it decomposes the goal
into a durable backlog, works one item per cron tick, swarms subagents on the
parallel parts, verifies its own work against acceptance criteria it can
actually execute, and reports only at checkpoints.

Ships approval-first, with a per-program deny-list, three-strike escalation,
and a kill switch every tick checks before anything else.

MIT. Issues and pull requests welcome.

## What we build

**Autonomous agents** — systems that take a goal and work it unattended, with
real guardrails, verification, and escalation rather than a demo loop.

**Web3 infrastructure** — Solana and EVM programs, revenue-sharing primitives,
and on-chain settlement for the cases where the trust assumption actually
matters.

**Developer tools** — the scaffolding, skills, and automation that shorten the
distance between an idea and something running in production.

**Product engineering** — full-stack SaaS, APIs, and marketing surfaces, built
to ship.
